## Descripción del repositorio

Este repositorio contiene las tareas del módulo **Entornos de Desarrollo** (1.º DAM/DAW). En esta entrega se trabaja la tarea sobre los elementos y herramientas que intervienen en el desarrollo de un programa informático.

## Objetivo de la tarea

Reconocer los elementos que intervienen en el desarrollo de un programa, diferenciando entre **código fuente**, **código objeto** y **código ejecutable**, y clasificar los lenguajes de programación según su nivel de abstracción y su paradigma (**imperativo** y **declarativo**).

## Contenido

### Parte 1. Análisis teórico de conceptos
- **Conceptos básicos:** qué son el código fuente, el código objeto y el código ejecutable, y las fases que sigue un programa hasta ejecutarse en el procesador (análisis léxico, sintáctico y semántico, generación de código intermedio, optimización y generación de código final), con ejemplos de cada una.
- **Clasificación de lenguajes:** según su nivel de abstracción (alto, medio y bajo) y según su paradigma (imperativo y declarativo), con al menos dos ejemplos justificados por categoría.

### Parte 2. Actividad práctica y de análisis
- **Identificación de paradigmas:** análisis de cuatro fragmentos (suma de una lista, consulta a una base de datos, factorial recursivo y filtrado de productos) indicando y justificando si son imperativos o declarativos.
- **Imperativo vs. declarativo:** descripción de una actividad cotidiana de las dos formas, con una comparación de las ventajas y desventajas de cada enfoque.
